# Security

Report a vulnerability privately through GitHub:
https://github.com/jamiebullock/LibXtract/security/advisories/new

Do not open a public issue for a security problem. Include the affected
function, the input that triggers it, and the platform and compiler, so the
report can be reproduced.

Reports are acknowledged as they are read. A fix lands on `main` with a
release note; the advisory is published once the fix is available. Only the
latest 1.x release is supported.
